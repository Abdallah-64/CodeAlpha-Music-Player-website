A modern, responsive music player website built as part of the CodeAlpha Frontend Development Internship.
Website: [https://codealpha-music-player-website.netlify.app](https://codealpha-music-player-website.netlify.app)
Source Code: [https://github.com/Abdallah-64/CodeAlpha-Music-Player-website](https://github.com/Abdallah-64/CodeAlpha-Music-Player-website)
This project is a frontend Music Player website created using HTML, CSS, and JavaScript.
The website provides an interactive music player interface where users can control audio playback and view information about the currently playing song.
- ▶️ Play music
- ⏸️ Pause music
- ⏮️ Previous song
- ⏭️ Next song
- 🎵 Display song title
- 🎤 Display artist name
- ⏱️ Display song duration
- 📊 Music progress bar
- 🔊 Volume control
- 📱 Responsive design
- ✨ Smooth transitions and interactive controls
- HTML5 — Website structure
- CSS3 — Styling, layout, responsiveness, and transitions
- JavaScript — Audio controls and music player functionality

1. Clone the repository:
```bash
git clone https://github.com/Abdallah-64/CodeAlpha-Music-Player-website.git

```
2. Open the project folder:
```bash
cd CodeAlpha-Music-Player-website

```
3. Open index.html in your browser.
